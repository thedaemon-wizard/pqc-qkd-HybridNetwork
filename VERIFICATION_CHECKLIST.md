# Verification checklist

What must be checked before a release, and how. Automated items are gated by
[CI](.github/workflows/ci.yml), except where a row says that part of it runs
only locally; the browser items are manual because they check things a
headless assertion does not: layout, legibility, and whether a control does
what its label says.

Order: **local build → local browser → PR + CI → demo redeploy → demo browser**.

The ids of this repository's own commits in this file are those of the
history as rewritten on 2026-09-26 (row 6.12b). A CI run cited by number ran
on the pre-rewrite commit, so its page on GitHub shows a different id for the
same change. Three ids in row 2.13 -- `16cbf1f`, `05e15db` and `a7061f9` --
were never on `main`: they were pull-request branch commits, and they resolve
on GitHub, not in a clone. Ids of other repositories were not rewritten and
are not in the rewrite's commit map: arnika's `3a8cc13`, `f4cf9ba`, `3e02741`
and `9d4433200d85`, Rosenpass's `512fe42`, strongSwan's `50177b40` and the
NIST ACVP-Server commit `15c0f3de`.
